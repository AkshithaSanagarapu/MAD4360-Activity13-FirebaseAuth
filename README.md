This is a simple Product Manager app I developed using Flutter and Firebase Cloud Firestore. The app allows users to add, view, update, and delete products. Each product has a name and price, and the information is stored in Firebase.

I also added a search option to find products by name and a price filter to display products within a selected price range. The product list updates automatically when changes are made in Firestore.

## Features

- Add new products with a name and price.
- View products stored in Firebase.
- Edit existing product details.
- Delete products.
- Search products by name.
- Filter products by maximum price.
- Reset search and filter options.
- Validate product details before saving.

## Technologies Used

- Flutter and Dart
- Firebase Cloud Firestore
- Android Studio / Android Emulator

## How to Run

1. Clone this repository.
2. Open the project in Android Studio or VS Code.
3. Make sure Flutter and Firebase are configured.
4. Run `flutter pub get` to install dependencies.
5. Run `flutter run` to launch the app.

The app requires a configured Firebase project and an internet connection to access Cloud Firestore.
